# UI/UX proposals — not implemented

These are a separate product backlog. None is necessary to deploy the measurement work, and none changes in these PRs.

1. **Offer a clear next action after signup.** Adapt the next step to web, assistant and CLI entry, using the actual missing prerequisite: authorize the assistant, connect a social account, or create the first post. Measure improvement in first successful tool use and publishing within seven days.
2. **Make the first post easier to complete.** Consider a guided first draft with a safe preview and an explicit publishing decision. Preserve work through account connection and authentication. Evaluate connected-but-never-published cohorts before choosing the intervention.
3. **Improve connection and publishing recovery.** Explain the specific recoverable prerequisite, preserve the draft, and provide a direct retry or reconnect path. Prioritize the platforms and failure codes observed in the new ledger and logs.
4. **Make trial value and timing clear.** Show the actual expiry and what requires payment, and consider permission-appropriate reminders tied to activation progress. Evaluate seven-day and extended trials separately. Any email, notification or billing copy requires separate approval.
5. **Help activated users choose a paid plan.** Review plan clarity, pricing/value explanation, billing-error recovery and saved work at expiry. Test one hypothesis at a time in the published-but-unpaid cohort after its payment window matures.
6. **Consider a lightweight acquisition survey.** An optional “Where did you hear about us?” can describe untagged/assistant-native discovery. Store self-reported source separately from observed attribution. Review response burden, wording and privacy before adding it.
7. **Add an operator dashboard if useful.** The new private JSON report can later power source/entry/release cohorts, milestone timing, expired-trial segments and measurement-health charts. Keep age-matched denominators and unknown coverage visible. No new operator screen is included in the measurement PR.
