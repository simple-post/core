# Scheduler widget fonts

These unmodified Latin variable WOFF2 subsets are the Inter and JetBrains Mono assets used by the Scheduler's `next/font/google` build. The widgets bundle them locally to match the web app without depending on the host's fonts or a third-party font request. Other scripts use the system fallback.

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Both are distributed under the included SIL Open Font License files.
