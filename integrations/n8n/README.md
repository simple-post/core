# SimplePost for n8n

The [SimplePost n8n node](https://github.com/simple-post/n8n-nodes-simplepost)
is developed and released from its dedicated repository. Install it from
npm as [`n8n-nodes-simplepost`](https://www.npmjs.com/package/n8n-nodes-simplepost).
